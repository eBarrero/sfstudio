# PBI-026: Detalle, filtros y navegación de diferencias

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: L
- Dependencias: PBI-025

## Historia de usuario

Como usuario, quiero localizar rápidamente una diferencia y abrir el objeto correspondiente en cualquiera de las orgs.

## Objetivo

Presentar DiffResult jerárquico y navegable sin perder contexto.

## Alcance

- Filtros ADDED, REMOVED, MODIFIED y texto.
- Jerarquía objeto -> campo/relación -> propiedad.
- Before/after claros para propiedades.
- Acciones abrir en origen y abrir en destino.
- Preservar ComparisonSession al navegar y volver.

## Criterios de aceptación

- Filtros combinados producen resultados previsibles.
- Cada diferencia muestra ruta API estable.
- Valores largos/picklists son legibles y accesibles.
- Abrir origen/destino cambia org activa de forma explícita.
- Volver conserva filtros y snapshots.

## Pruebas requeridas

- Unitarias de filtrado/presentación.
- E2E diferencia -> explorador -> volver.
- Rendimiento de lista con diff grande.

## Fuera de alcance

- Editor para aplicar cambios.
- Comparación visual de datos de registros.

## Definition of Done

- Criterios demostrados en CI y en la demo integrada.
- Accesibilidad básica y paridad ratón/comando comprobadas.
- Seguridad y persistencia revisadas sin excepciones silenciosas.
- Guías de usuario y operación actualizadas.
