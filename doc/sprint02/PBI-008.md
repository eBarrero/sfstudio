# PBI-008: Desconexión y reautenticación explícitas

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: M
- Dependencias: PBI-007

## Historia de usuario

Como usuario, quiero entender cuándo una org perdió su conexión y reconectarla sin perder el resto del workspace.

## Objetivo

Implementar cierre real por org, cierre completo del workspace y el estado REAUTH_REQUIRED.

## Alcance

- DELETE /api/v1/workspace/orgs/:orgKey para desconectar una org.
- DELETE /api/v1/workspace para cerrar todo.
- Revocar token cuando sea posible y eliminar driver.
- Borrar cookie al cerrar el workspace.
- Traducir pool ausente/token expirado a REAUTH_REQUIRED con login action.

## Criterios de aceptación

- Desconectar una org no afecta a las demás.
- Cerrar el workspace elimina conexiones y cookie.
- Después de reiniciar el servidor, la org conocida aparece como REAUTH_REQUIRED.
- El cliente puede iniciar OAuth de nuevo conservando su OrgKey.
- Logout deja de ser un método vacío.

## Pruebas requeridas

- Integración de desconexión individual y total.
- Reinicio simulado con Mongo conservado y registro vacío.
- Idempotencia al desconectar dos veces.

## Fuera de alcance

- Guardar refresh tokens.
- Reconexión automática sin intervención.

## Definition of Done

- Criterios demostrados con pruebas automatizadas o evidencia manual indicada.
- Contratos y errores públicos documentados.
- Ningún token aparece en MongoDB, respuestas o logs.
