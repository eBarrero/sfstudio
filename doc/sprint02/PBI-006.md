# PBI-006: OAuth correcto para producción y sandbox

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: L
- Dependencias: PBI-005

## Historia de usuario

Como usuario, quiero conectar cualquier org autorizada con el mismo flujo, sea producción o sandbox.

## Objetivo

Corregir selección de login host y eliminar la lógica duplicada o errónea de tecnología.

## Alcance

- Corregir reconocimiento de SF_Prod y SF_Test.
- Transportar loginHost dentro del contexto OAuth validado.
- Usar login.salesforce.com o test.salesforce.com en autorización e intercambio según contexto.
- Mantener capacidades idénticas después del login.
- Preparar configuración compatible con External Client App sin bloquear Connected Apps existentes.

## Criterios de aceptación

- El login de producción intercambia el code contra el host correcto.
- El login de sandbox usa el host de sandbox.
- Ningún host se deduce de datos manipulables del callback.
- Ambos flujos producen el mismo OrgConnection normalizado.
- Errores de Salesforce se traducen a códigos internos sin filtrar detalles sensibles.

## Pruebas requeridas

- Integración con drivers OAuth falsos para ambos hosts.
- Prueba manual controlada con una org de cada tipo.

## Fuera de alcance

- Diferenciar funcionalidades por entorno.
- Client credentials flow.

## Definition of Done

- Criterios demostrados con pruebas automatizadas o evidencia manual indicada.
- Contratos y errores públicos documentados.
- Ningún token aparece en MongoDB, respuestas o logs.
