# PBI-011: Dispatcher único para ratón y comandos

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: L
- Dependencias: PBI-010

## Historia de usuario

Como usuario, quiero ejecutar cualquier acción con ratón o comando y obtener exactamente el mismo comportamiento.

## Objetivo

Separar definición/ejecución de acciones de sus adaptadores de entrada UI y consola.

## Alcance

- Definir ActionId, parámetros tipados y resultado.
- Crear dispatcher central con autorización por contexto.
- Hacer que botones y menús despachen ActionId.
- Hacer que el parser de comandos produzca el mismo ActionId.
- Añadir comandos org list, org use, org close y org reconnect.

## Criterios de aceptación

- Una acción no tiene dos implementaciones de negocio.
- Clic y comando generan el mismo ActionId y parámetros.
- Comandos inválidos no mutan estado y devuelven ayuda.
- El registro no duplica comandos tras re-render o reinicialización.
- Cada nueva acción debe declarar UI o justificar por qué no aplica.

## Pruebas requeridas

- Unitarias parser -> Action.
- Unitarias dispatcher por contexto.
- Tests parametrizados comparando clic y comando.

## Fuera de alcance

- Sintaxis de scripting o macros.
- Autocompletado avanzado.

## Definition of Done

- Criterios cubiertos por pruebas.
- Componentes accesibles mediante teclado.
- Ratón y comando comparten ActionId y caso de uso.
- Documentación de comandos actualizada.
