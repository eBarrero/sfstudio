# PBI-017: Dominio SOQL puro y probado

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: L
- Dependencias: PBI-013

## Historia de usuario

Como usuario, quiero que la consulta generada sea válida y predecible antes de enviarla a Salesforce.

## Objetivo

Extraer AST, validación y renderer SOQL fuera de Zustand y corregir defectos conocidos.

## Alcance

- Unions discriminadas para raíz, relaciones padre y subqueries.
- Renderer puro para SELECT, FIELDS, WHERE, GROUP BY, ORDER BY, LIMIT y OFFSET soportados.
- Escape central de literales por tipo.
- Validación estructural en lugar de contar SELECT/FROM.
- Corregir SELECT SELECT FIELDS y reglas de agregación.

## Criterios de aceptación

- FIELDS(ALL/CUSTOM/STANDARD) genera sintaxis válida.
- Una consulta inválida devuelve errores estructurados con ubicación.
- El renderer no depende de React, Zustand, fetch o globals.
- Mismos AST producen exactamente el mismo texto.
- El subconjunto soportado y sus límites están documentados.

## Pruebas requeridas

- Tabla de casos simples, relaciones, subqueries y agregados.
- Property/golden tests para escaping.
- Regresiones de bugs históricos.

## Fuera de alcance

- Parser completo de SOQL libre.
- Todas las funciones posibles de Salesforce.

## Definition of Done

- Casos positivos y negativos automatizados.
- Solo SELECT está permitido en esta fase.
- Resultados y query text sensible no se persisten ni registran.
- UI y comandos comparten acciones.
