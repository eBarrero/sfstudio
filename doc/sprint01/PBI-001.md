# PBI-001: Pipeline local reproducible y CI mínima

- Estado: Implementada; pendiente de validación en GitHub Actions
- Prioridad: Must
- Tamaño relativo: M
- Dependencias: Ninguna

## Historia de usuario

Como desarrollador, quiero validar el repositorio con comandos raíz consistentes para detectar regresiones antes de desplegar.

## Objetivo

Unificar build, typecheck, lint, test y audit; reparar el script ESLint y el arranque de Jest sin añadir todavía pruebas funcionales extensas.

## Alcance

- Añadir scripts raíz build, typecheck, lint y test.
- Eliminar opciones ESLint incompatibles con flat config.
- Resolver el setup de Jest usando el fetch disponible o una dependencia explícita.
- Configurar CI con npm ci, typecheck, lint, tests y build.
- Fijar Node 24 mediante .node-version y engines.node.

## Criterios de aceptación

- Dado un checkout limpio, cuando se ejecuta npm ci y los comandos raíz, todos terminan con código 0.
- Dado un error TypeScript, lint o test, cuando corre CI, el pipeline falla.
- El start de producción no compila en segundo plano ni usa el operador &.
- La documentación enumera los comandos canónicos.

## Pruebas requeridas

- Ejecución local de todos los scripts raíz.
- Prueba de CI introduciendo temporalmente un fallo controlado.

## Fuera de alcance

- Actualizar React, Vite o Jest a una versión mayor.
- Crear pruebas de negocio completas.

## Definition of Done

- Todos los criterios de aceptación están demostrados.
- Las pruebas nuevas pasan en CI.
- No se introducen secretos ni datos personales en fixtures o logs.
- La documentación afectada queda actualizada.

## Evidencia de implementación

Validación realizada el 25 de octubre de 2026 con Node 24.22.1 y npm 12.2.1:

- `npm ci`: instalación limpia completada.
- `npm run typecheck`: código 0.
- `npm run lint`: código 0 y cero advertencias permitidas.
- `npm test`: 2 suites y 2 pruebas superadas.
- `npm run build`: API y aplicación web compiladas.
- `npm run audit`: cero vulnerabilidades en dependencias de producción.
- Prueba negativa: un error TypeScript temporal hizo fallar `npm run typecheck` con código distinto de 0; tras retirarlo, el control volvió a pasar.
- La ejecución alojada de GitHub Actions queda pendiente del primer `push` o `pull_request` que incluya el workflow.
