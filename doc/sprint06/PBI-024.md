# PBI-024: Diff de relaciones y suite de contratos

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: L
- Dependencias: PBI-023

## Historia de usuario

Como usuario, quiero detectar diferencias de relaciones padre/hijo que pueden romper consultas o automatizaciones.

## Objetivo

Comparar lookup/master-detail y child relationships, y cerrar la suite del motor completo.

## Alcance

- Normalizar relaciones por objeto, campo y relationshipName.
- Comparar referenceTo, cascade/restricted delete y propiedades disponibles.
- Relacionar el cambio con el campo correspondiente.
- Fixtures anonimizados representativos I/UAT.
- Contrato JSON versionado del DiffResult.

## Criterios de aceptación

- Una relación renombrada, añadida o eliminada se detecta.
- Relaciones polimórficas se comparan como conjuntos.
- No se duplica el mismo cambio como campo y relación sin referencia entre ambos.
- El DiffResult completo pasa snapshot tests.
- El motor procesa el volumen esperado sin bloquear perceptiblemente.

## Pruebas requeridas

- Unitarias de relaciones simples, hijas y polimórficas.
- Golden test completo I/UAT.
- Benchmark con snapshot grande y umbral documentado.

## Fuera de alcance

- Visualización React.
- Comparar reglas de sharing o permisos.

## Definition of Done

- Resultado determinista, serializable y versionado.
- Pruebas con fixtures anonimizados cubren before/after.
- El dominio no importa React, Zustand, IndexedDB ni clientes HTTP.
- Rendimiento medido con un snapshot representativo.
