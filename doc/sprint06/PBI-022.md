# PBI-022: Diff determinista de objetos

- Estado: Propuesta
- Prioridad: Must
- Tamaño relativo: M
- Dependencias: PBI-021, PBI-013

## Historia de usuario

Como usuario, quiero saber qué objetos existen solo en Integración, solo en UAT o han cambiado.

## Objetivo

Comparar colecciones de objetos por API name y propiedades seleccionadas.

## Alcance

- Estados ADDED, REMOVED, MODIFIED y UNCHANGED.
- Comparar label y capacidades estructurales configuradas.
- Resultado ordenado por API name.
- Resumen de conteos.
- Lista configurable de propiedades ignoradas.

## Criterios de aceptación

- El orden de entrada no cambia el diff.
- Objetos exclusivos se clasifican desde la perspectiva origen/destino documentada.
- Una propiedad ignorada no genera modificación.
- Cada cambio indica before y after.
- No se compara por índice local ni label.

## Pruebas requeridas

- Fixtures con todos los estados.
- Simetría esperada al invertir origen/destino.
- Orden aleatorio de entrada.

## Fuera de alcance

- Comparar datos de registros.
- Apex, Flow y layouts.

## Definition of Done

- Resultado determinista, serializable y versionado.
- Pruebas con fixtures anonimizados cubren before/after.
- El dominio no importa React, Zustand, IndexedDB ni clientes HTTP.
- Rendimiento medido con un snapshot representativo.
