# PBI-029: Eliminar el contexto de org duplicado

- Estado: Implementada
- Prioridad: Must
- Tamaño relativo: S
- Dependencias: ninguna dentro del sprint 08

## Historia de usuario

Como usuario, quiero ver la organización activa una sola vez para disponer de más espacio de trabajo.

## Alcance

- Quitar `ActiveOrgContext` de `frame_editor` en `HomePage`.
- Mantener el contexto que aparece en `frame_explorer`.
- Evitar cambios en la selección de org y en la navegación.

## Criterios de aceptación

- `frame_editor` no renderiza `ActiveOrgContext` en ninguna vista.
- El explorador sigue mostrando alias, usuario, organization ID y tipo de entorno de la org activa.
- Cambiar la org activa actualiza el contexto visible.

## Pruebas requeridas

- Prueba de componente para ausencia de duplicado y actualización al cambiar de org.

## Definition of Done

- No se elimina información de identidad necesaria para el contexto activo.
- Build, lint y pruebas afectadas pasan.

## Evidencia

- `app/e2e/sprint08HomePage.test.tsx` comprueba que el contexto activo aparece una sola vez con el editor visible.
